## 简介

Terry Toolbox 是一个面向 Linux 服务器的中文菜单工具箱。登录服务器后运行脚本，输入编号就能进入相应功能。

启动菜单本身不安装软件、不修改配置。涉及安装、修改系统或重启的操作，会先显示内容并请求确认。B18 暂时保留，以后再补。

## 使用方法

### 一键入口

```bash
curl -fsSL http://sh.uw.cx | sudo bash
```

想先看代码再跑：

```bash
curl -fsSL http://sh.uw.cx -o toolbox.sh
less toolbox.sh
sudo bash toolbox.sh
```

也可以先核对哈希：

```bash
curl -fsSL http://sh.uw.cx | sha256sum
```

与仓库 `docs/index.html` 的哈希对比，一致再执行。**当前发布版本的 SHA-256**：`46b81ffdea546e90348ae398c1d35e7d732c6c50ce3b82ec12e69bef8fcfb0e4`（每次发布后更新）。

服务端下载的是单文件版本，全部模块已经打包进去，不需要准备其他文件。Debian / Ubuntu 为当前主要支持环境，Alpine 仅部分功能。

### 菜单怎么操作？

进入菜单后输入编号，例如：

- 输入 `DIAG`：查看系统、内存、磁盘、网络和监听端口。
- 输入 `M1`：进入 BBR 设置。
- 输入 `B1`：进入 Docker 安装。
- 输入 `A4`：进入 Hysteria 2 的安装 / 卸载 / 状态。
- 输入 `0`：退出。

软件安装类功能通常需要 root 权限；具体以菜单提示为准。

## 安全提示

- 脚本操作的是**当前登录的服务器**。安装软件、修改网络或重启可能影响现有业务，操作前请备份并保留独立登录方式。
- 体检结果可能包含 IP 地址和监听端口，分享前请检查隐私信息。
- Docker 应用默认使用本机端口，不等于对其他容器或宿主机用户完全隔离；部署密码管理器等应用前，还需要配置 HTTPS、认证和备份。
- 不要盲目运行任何来源不明的远程脚本。正式发布后，建议先下载并查看脚本，再核对发布版本的校验值。
