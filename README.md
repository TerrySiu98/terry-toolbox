## 这个工具箱做什么？

用一个中文菜单管理服务器。进入菜单时不会自动安装软件；安装或修改系统前会显示操作内容，并要求确认。

计划涵盖系统工具、网络服务和常用应用。B18 暂时留空，以后再补。

## 开发进度

- **已开发**：只读系统体检、BBR、基础依赖、Docker 安装、修改 root 密码、重启，以及指定目标的路由追踪。
- **正在验证**：Hysteria 2、swap 和 Docker 应用部署。这些功能目前只通过了模拟测试，还没有完成真实环境验收。
- **尚未实现**：其他菜单功能。开发版会明确提示，不会把空菜单当成可用功能。

## 使用前请注意

工具可能修改系统、安装软件或重启服务器。请先阅读脚本、确认操作范围，并准备备份和独立登录方式。系统体检会显示 IP 地址和监听端口，分享结果前请检查隐私信息。
