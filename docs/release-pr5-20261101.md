## 修复范围

- Xray 固定版本由已撤版的 26.10.29 调整为 26.10.31，并更新 amd64/arm64 白名单；这只更新今后安装入口，**不会替现有机器自动升级 Xray**。
- 非 root 流式入口的提权重下载强制 HTTPS，重定向也只允许 HTTPS。菜单短命令保留。
- B23 连续切换 DNS 时不再把工具第一次生成的 drop-in 当作原始配置；有原备份时恢复原文件，没有原文件时删除工具生成的 drop-in。
- 端口归属只查询指定协议、指定端口，不把同一进程在其他端口的监听误认作目标服务。
- `sudo -E` 保留普通用户 HOME 时，缺失父目录由 HOME 属主身份独占创建，不 chown/chmod 既有目录；符号链接/冲突拒绝，应用自身数据目录继续使用受限权限。
- Relay 单元采用身份台账和本次 exclusive-create claim；失败回滚不得接管另一合法安装。停止非零、Job/PID/监听残留、读取失败或归属变化均保留资源。
- Relay 的 `systemctl show` 按 Key=Value 解析，不依赖输出顺序；缺失/重复/未知字段拒绝。未尝试启动的 not-found 分支也要求完整 inactive/dead/PID0/no-job 一致状态。
- Relay 删除门禁显式检查 `ss` 返回码：非零且没有 stdout 仍是未知，不能当作无监听。
- Cloudflare token 的空白/控制字符在请求前拒绝，防止 HTTP 库错误包含原 token。
