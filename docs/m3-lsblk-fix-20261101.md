# M3 旧版 lsblk 兼容修复（2026-11-01）

## 问题与修复

进入 M3 → 准备重装 → Alpine 时，旧版 `lsblk` 报 `unknown column: MOUNTPOINTS,...`，工具箱随后报告“lsblk 回读失败”。这不是缺少软件包：在 Debian 11 自带的 util-linux 2.36.1 上复现后，同一完整字段列表仅将复数 `MOUNTPOINTS` 改为单数 `MOUNTPOINT` 即可读取。

候选改用旧版和新版均支持的 `MOUNTPOINT`，递归校验后归一为原有 `mountpoints` 数组。磁盘容量、序列号、WWN、分区表 UUID 等全部身份字段继续读取；物理磁盘/sysfs、holder、根/引导挂载祖先与取消时的磁盘身份复核保持原流程。挂载字段缺失、错误类型或未知子节点结构仍拒绝。已挂载的 loop/snap 和 swap loop 仍拒绝，无挂载 loop 的支持范围保持不变。没有增加系统工具升级或自动重试。
