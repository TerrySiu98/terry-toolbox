# 开发环境与目录

更新：2026-11-12。本文件记录当前开发分工；实际主机、凭据和资料恢复状态由维护者的项目私有记录提供。历史交接与发布记录保留原始事实，不作为重新执行的授权。

## 工作电脑

- Mac mini 长期源码工作区使用 `~/Codex/projects/terry-toolbox`，保存源码、Git 历史、文档、必要资源与受保护连接凭据。MacBook 旧工作区在恢复验收前保留；过渡任务使用所在机器真实存在的入口。
- 轻量源码便于查看、编辑与 Git 同步，可以留在 Mac。大型恢复包、数据库与测试机镜像、历史产物和依赖缓存不搬入 Mac，也不以改放另一个本机目录作为保全例外；恢复时按仓库入口在开发机取用或重建。
- Codex 内部状态沿用 `~/.codex`，总规范为 `~/.codex/AGENTS.md`；无项目聊天工作文件使用 `~/Codex/chats/<日期>/<聊天目录>`。聊天目录不能替代会话状态，应用管理的工作树不手动移动。
- 本项目连接入口使用 `.private/ssh/config`，必要密钥和固定 `known_hosts` 保存在同一受保护目录。目录权限为 `0700`，秘密文件为 `0600`，`.private/` 排除 Git 与所有公开源码包和构建上下文。
- 实际开发机别名、工作目录、旧端来源、私有证据位置及资料恢复缺口写入 `.private/DEVELOPMENT-LOCAL.md`。连接前读取此记录与当前配置，核验目标身份和已固定主机指纹；不从历史 IP 猜测、不自动接受未知 key、不引用其他项目的私有入口。
- 公开规范只写通用路径和分工，不写个人绝对 home 路径、私有地址、主机指纹或凭据。`.gitignore` 不能保护已跟踪秘密，提交与打包前仍须检查内容。

## 执行与发行

- 日常依赖、合成测试、预览、容器、数据库、编译与发布工具放在专用开发服务器的本项目隔离目录，源码目录为 `/srv/projects/terry-toolbox/repo`。依赖、工具、缓存、私有记录和候选产物分别保存在本项目目录内，不混入 Mac 源码提交。
- 每次先检查两端 Git 分支、HEAD、暂存与未暂存内容，保护 WIP 和未推送提交；按明确分支同步。开始重任务前核对资源占用，控制并发，不覆盖其他项目源码或修改共用宿主设置。
- 测试脚本仍有受保护 root fixture、工具版本与新建输出目录等约束，按 README、HANDOFF 和脚本当前门禁执行；不在迁移中放宽门禁，也不在 Mac 回退运行。缺少适用环境时记录缺口并准备隔离环境。
- 真实服务安装/卸载、内核、网络、防火墙、磁盘、重装和重启验收使用用户授权的专用临时测试机；共用开发机、用户 Mac、生产与其他项目机器不能充当可擦除目标。
- 发行继续现有 Cloudflare Workers 流程，按本次发布授权核对构建、备份、上传和外部回读。源码或文档同步不触发发布、域名变更或历史 adapter 重跑，GitHub 继续保存可公开的源码和审查记录。

## 迁移与保留

- 恢复前核对源和目标状态，保留当前分支、Git 历史、WIP、必要资源及唯一私有资料。只克隆主线不能代替恢复未推送工作，改路径也不能代替实际搬迁与验收。
- 原始日志、凭据、测试机镜像、数据库、私有发行恢复资料与唯一故障证据继续放在已确认的受保护来源，按需精确恢复；不整体搬入 Mac mini 日常源码目录。可重建依赖和构建缓存不默认迁移。
- GitHub 保存完整已审源码、必要资源、构建与发行脚本、配置模板及文档。开发机测试数据按用户当前要求可丢弃，失联后从仓库重建新的隔离测试环境，不再为测试数据建立 Mac 独立恢复副本。检查旧分支和未推送修改后再判断源码已完整保存；新的主线不能代替尚未保存的工作。
- Cloudflare Workers 已发布内容不向开发机或 Mac 回源。重新发布仍需对应 Cloudflare 账户、令牌和域名权限；本次源码迁移没有验证新机发布认证，也不授权发布或重绑定。恢复源码、重建测试环境与恢复生产身份分别核验。
- 核验源码与资料哈希、权限、聊天正文、附件、项目关联、Git/SSH 与远程工具，再记录独立运行和仍留旧端的缺口。历史正文和证据来源路径不为整理目录盲改。
- 在新机完整性和独立运行验收前保留旧端原件；未解决证据、唯一回退资料、生产凭据及真实运行数据不按缓存删除。生产所需非 Git 数据走受保护备份；可重建测试数据不作为旧机迁移的额外备份要求，公开仓库不保存秘密。
